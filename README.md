# Secret Garden — фотостудия «Тайный Сад»

Сайт фотостудии Secret Garden (Рязань). Структура и тексты — по образцу secretgarden62.ru; дизайн в светлых бело-розовых тонах с фирменным зелёным логотипом.

## Разделы

- Шапка — список сильных сторон студии и две фотографии-коллаж
- Студия — вступление и лента фотографий
- Фотопроекты — готовые проекты, у каждого своя галерея
- Локации — 9 фотозон, у каждой своя галерея
- Гардероб — платья в аренду
- Оборудование — список приборов с фото и описанием
- Свет — система освещения
- Стоимость, Правила, Контакты (карта, соцсети, онлайн-запись)
- `/oferta` — договор оферты
- `/privacy` — политика конфиденциальности

## Админ-панель

`/admin` — вход по паролю. Редактируются все разделы с фотографиями:

| Раздел       | Что можно делать                                              |
| ------------ | ------------------------------------------------------------- |
| Шапка        | загружать и переставлять фото шапки (на сайте показываются первые две) |
| Студия       | загружать (сразу несколько), подписывать, менять порядок, удалять фото |
| Фотопроекты  | добавлять/редактировать/удалять проекты, менять обложку и порядок, вести галерею каждого проекта |
| Локации      | добавлять/редактировать/удалять локации, менять обложку и порядок, вести галерею каждой локации |
| Гардероб     | загружать, подписывать, менять порядок, удалять фото          |
| Оборудование | добавлять/редактировать/удалять позиции с фото, менять порядок |
| Свет         | загружать, подписывать, менять порядок, удалять фото          |
| Разделы      | скрывать с сайта / публиковать блоки Студия, Фотопроекты, Локации, Гардероб, Оборудование, Свет (скрытый раздел пропадает и из меню, контент сохраняется) |
| Безопасность | сменить пароль, создать одноразовый код восстановления       |

Загружаемые изображения автоматически сжимаются (WebP, до 1800 px по ширине).

### Пароль и восстановление

- Пока пароль не менялся, действует `ADMIN_PASSWORD` из окружения.
- После смены пароля во вкладке «Безопасность» его хеш (scrypt) хранится в `data/auth.json`; все старые сессии сбрасываются.
- Там же можно создать **код восстановления** — он показывается один раз. Если пароль забыт, на странице входа нажмите «Забыли пароль?», введите код и задайте новый пароль. Код одноразовый: после использования создайте новый.
- Если утерян и пароль, и код — удалите на сервере `data/auth.json`, и снова будет действовать `ADMIN_PASSWORD`.
- После 8 неверных попыток входа с одного IP вход блокируется на 15 минут.

## Запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

- Сайт: http://localhost:3000
- Админка: http://localhost:3000/admin (пароль по умолчанию `secretgarden`)

Production:

```bash
npm run build
npm run start
```

## Переменные окружения

```bash
ADMIN_PASSWORD=secretgarden                       # стартовый пароль админки
ADMIN_SECRET=change-me-to-a-long-random-string    # секрет подписи cookie
NEXT_PUBLIC_SITE_URL=https://secretgarden62.ru    # публичный адрес сайта (canonical, OG, sitemap)
YANDEX_VERIFICATION=                              # код из Яндекс Вебмастера (необязательно)
GOOGLE_SITE_VERIFICATION=                         # код из Google Search Console (необязательно)
```

## SEO

- `title`/`description`/`keywords`, canonical-ссылки, Open Graph и Twitter-карточки (обложка `public/og-cover.jpg`), `lang="ru"`.
- `/robots.txt` (закрыты `/admin` и `/api/`), `/sitemap.xml`, `/manifest.webmanifest` генерируются автоматически из `NEXT_PUBLIC_SITE_URL`.
- Микроразметка Schema.org (`LocalBusiness` с адресом, телефоном, ценами и фото; `WebSite`) на главной странице.
- Страница `/admin` закрыта от индексации (`noindex`).
- После публикации добавьте сайт в [Яндекс Вебмастер](https://webmaster.yandex.ru) и [Google Search Console](https://search.google.com/search-console), укажите коды подтверждения в переменных окружения и отправьте `sitemap.xml`.

## Хранение данных

- `data/content.json` — весь контент фоторазделов и флаги публикации разделов
- `data/auth.json` — хеш пароля и кода восстановления (создаётся при первой смене пароля, не коммитится)
- `public/images/` — исходные фотографии студии (в репозитории)
- `public/uploads/` — файлы, загруженные через админку (не коммитятся)

Каталоги `data/` и `public/uploads/` должны быть доступны на запись. На хостингах с временной файловой системой (например, Vercel) загрузки не сохраняются — используйте VPS или платформу с постоянным диском.
